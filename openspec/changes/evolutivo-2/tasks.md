# Tasks: Evolutivo 2

Conventions: `strict_tdd: false`, but every task ships its tests in the same commit (Jest + Supertest under `tests/routes`, `tests/services`, `tests/ui`). Prefer NEW test files (the temp db is shared per file). Names, endpoints, fields and collections follow `design.md` (authoritative). `npm test` must pass before each slice is pushed; `npm run test:coverage` (global 60%, per-file thresholds in `jest.config.js`) runs in the final task and must pass too. All new API fields are optional, so existing suites stay green. Each slice leaves master deployable (feature-branch-chain: one branch per slice, each based on the previous; delivery order below). `public/sw.js` `CACHE_NAME` goes to `selimsystem-v27` in the first UI slice and increments once per UI slice (v27 to v31).
