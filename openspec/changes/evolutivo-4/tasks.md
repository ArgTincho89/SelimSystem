# Tasks: Evolutivo 4

Conventions: `strict_tdd: false`, but every task ships its tests in the same commit (Jest + Supertest under `tests/routes`, `tests/services`, `tests/ui`). Prefer NEW test files (the temp db is shared per file). Names, endpoints, fields and collections follow `design.md` (authoritative).
